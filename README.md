# 思念你 · 情侣双向思念小程序

一个运行在手机上的情侣专属平台：一方点一下「想 TA」，另一方的手机**立刻**收到浪漫提示；
记录思念次数、日均、连续天数，支持回抱、表情、心情打卡、定时情话、恋爱日记与未来信件。
界面走温柔的粉紫浪漫风，专注给两个人提供情绪价值。

---

## 功能一览

| 模块 | 功能 |
|------|------|
| 绑定 | 一方生成 6 位邀请码，另一方输入即绑定（WebSocket 实时在线状态） |
| 思念主页 | 大爱心按钮「想 TA」一键送达；今日/累计/连续天数实时展示 |
| 收到思念 | 全屏爱心飘落动画 + 震动 + 语音式文案，可「回抱」或「我也想你」 |
| 互动 | 实时回抱 🤗、发表情逗 TA、心情打卡（开心/想念/难过…），并看到 TA 最近心情 |
| 情话 & 定时 | 内置情话库可复制；**定时情话**每天到点自动推送给双方 |
| 日记 & 信件 | 写恋爱日记 / 给未来的 TA 写一封信，对方实时收到并可读 |
| 统计 | 累计/日均/今日/连续天数、「谁更想谁」对比、近 14 天趋势图、拥抱次数 |
| 专属信物 & 惊喜 | 生成只属于两人的「信物码」，扫码即可解锁爱意卡片，收集成册（轻量方案，不采集人脸） |

## 一、启动后端（必须）

后端负责配对、实时推送、定时任务与数据持久化（JSON 文件，无需数据库）。

```bash
cd backend
npm install
npm start
# 看到 ❤️  情侣思念后端已启动: http://localhost:3000 即成功
```

- 默认端口 `3000`，可用 `PORT=8080 npm start` 修改。
- 想验证后端链路：`node test_client.js`（会模拟 A、B 两个客户端跑通全部功能）。

## 二、导入小程序

1. 下载安装「微信开发者工具」。
2. 选择「导入项目」→ 目录选 `miniprogram/` 文件夹。
3. AppID 可先用「测试号」(touristappid)，正式发布需填你自己的小程序 AppID。
4. 右上角「详情 → 本地设置」勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**（开发阶段必须勾，否则连不上本地后端）。

## 三、配置服务器地址（关键）

小程序需要知道后端在哪。两种方式二选一：

- **方式 A（推荐）**：打开 `miniprogram/app.js`，修改顶部两行：
  ```js
  serverUrl: 'http://你的电脑局域网IP:3000',   // 例如 http://192.168.1.50:3000
  wsUrl:     'ws://你的电脑局域网IP:3000',
  ```
- **方式 B**：进小程序「设置」页直接填并保存（会自动重连）。

> 电脑上用 `ipconfig`(Windows) / `ifconfig`(Mac) 查局域网 IP。手机和电脑需在同一 Wi-Fi。

## 四、体验双人实时

1. 在开发者工具里「编译」运行，或点「真机预览」用手机扫码。
2. 设备 A：填昵称 → 「生成邀请码」→ 把 6 位码发给 B。
3. 设备 B：填昵称 → 切到「输入邀请码」→ 加入。
4. A 点「想 TA」→ B 手机立刻弹出全屏爱心提示 + 震动 💗
5. 互相试试回抱、表情、写日记、设一条「1 分钟后」的定时情话验证推送。

## 四、专属信物 & 惊喜卡片（轻量方案，无生物识别风险）

用「专属信物码（二维码）」代替拍照识别人脸，既保留「扫一扫→惊喜」的仪式感，又完全避开人脸合规红线。

- 首页点「🎁 专属信物」进入 → 「生成信物码」会得到一张只属于你们两人的二维码；
- 把码亮给 TA，或保存图片互相扫；用微信「扫一扫」扫到后，自动解锁一张**爱意卡片**（共 12 张浪漫卡片可集齐）；
- 对方扫码时，你这边会实时收到「TA 解锁了一张爱意卡片 💌」提示；
- 卡片进「我的卡片册」，集齐 12 张有彩蛋。
- 信物码内容形如 `couple-token://房间号/密钥`，后端校验通过才解锁，扫到别人的码不会生效。

> 进阶：若日后想做「拍照识别对方」的人脸版本，需接入腾讯云人脸识别并落实单独同意/加密/影响评估等合规（详见可行性评估），本仓库当前采用零风险的信物码方案。

## 五、上线到真机（公网）

详见 **[DEPLOY.md](./DEPLOY.md)**：已内置 `Dockerfile`，可一键部署到 Railway / Render / 自有云服务器，拿到公网 `https/wss` 地址后填进小程序即可让两人异地随时互连。

1. 把 `backend/` 部署到一台有公网 IP 的服务器（或任意 Node 托管平台）。
2. 用 **反向代理（Nginx 等）配上 HTTPS / WSS**：微信要求正式环境必须是 `https://` 与 `wss://`。
3. 小程序后台「开发 → 开发管理 → 服务器域名 → socket 合法域名」加入你的 `wss://域名`；「request 合法域名」加入 `https://域名`。
4. 小程序 `app.js` 里的 `serverUrl / wsUrl` 改成公网地址，上传代码提交审核发布。

## 目录结构

```
couple-app/
├── backend/                # Node.js 实时后端
│   ├── server.js           # Express REST + ws WebSocket + 定时调度
│   ├── store.js            # JSON 文件持久化（房间/统计/定时/日记）
│   ├── test_client.js      # 自动化链路测试脚本
│   └── data/db.json        # 运行时自动生成的数据
└── miniprogram/            # 微信小程序源码
    ├── app.js / app.json / app.wxss
    ├── utils/              # api.js(REST) event.js(事件总线)
    ├── components/miss-overlay/   # 全局「收到思念」浪漫弹层
    └── pages/              # splash/pairing/home/interact/words/diary/stats/settings
```
